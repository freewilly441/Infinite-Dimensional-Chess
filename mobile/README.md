# Infinite Dimensional Chess — Mobile (Capacitor)

Android and iOS wrapper for the Infinite Dimensional Chess web app, built with [Capacitor](https://capacitorjs.com/).

The game logic runs unchanged inside a native WebView. Three.js is loaded from CDN; all other game JS/CSS lives in `www/assets/` (synced from `../static/`).

---

## Prerequisites

| Tool | Version | Notes |
|------|---------|-------|
| Node.js | 18+ | |
| npm | 9+ | |
| Android Studio | Latest | Android builds only |
| Xcode 15+ | Latest | iOS builds only (macOS required) |

---

## First-time setup

```bash
cd mobile
npm install
npm run sync-assets      # copies JS/CSS/sounds from ../static/ into www/assets/
npx cap add android      # generate Android platform folder
npx cap add ios          # generate iOS platform folder (macOS only)
npx cap sync             # copy www/ into native projects
```

---

## Development workflow

Whenever you change game files in `../static/`:

```bash
cd mobile
npm run build            # sync-assets + cap sync in one step
```

Then open the native IDE:

```bash
npm run open:android     # opens Android Studio
npm run open:ios         # opens Xcode (macOS only)
```

Run from the IDE on a device or emulator.

## Project structure

```

├── capacitor.config.ts   # app ID, name, webDir, plugin config
├── package.json          # Capacitor dependencies + npm scripts
├── sync-assets.js        # copies game files from ../static/ → www/assets/

│   ├── n-dimensional-chess.html
│   ├── infinite-chessboard.html
│   ├── mobile-touch.css        # touch-specific overrides

│       ├── infinite_chessboard_module.js
│       ├── keyboard_controller.js
│       ├── styles.css
│       └── sounds/
├── android/              # generated by npx cap add android (not committed)
└── ios/                  # generated by npx cap add ios (not committed)
```

## What changed vs. the web version

| Area | Change |
|------|--------|
| Navigation links | `/n-dimensional-chess` → `./n-dimensional-chess.html` |
| Static asset paths | `/static/foo.js` → `./assets/foo.js` |
| Viewport meta | Added `viewport-fit=cover` + Apple mobile-web-app tags |
| Touch controls | `mobile-touch.css` adds safe-area insets, 44 px hit targets, `touch-action: none` on canvas |
| Particle count | Landing page reduced from 50 → 20 for mobile performance |
| Welcome modal copy | Updated control descriptions (tap/pinch instead of mouse/scroll) |

Three.js and OrbitControls still load from unpkg CDN — an internet connection is required to play.
